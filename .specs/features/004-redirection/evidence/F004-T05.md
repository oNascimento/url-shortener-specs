## Continuidade e limites

### Topologia e cenários

A API usa o host HTTP de integração existente e PostgreSQL real. Os dois redirecionadores são hosts Kestrel independentes, com portas, DI e conexões RabbitMQ distintas, no processo dos testes; Caddy 2.10.2 executa em container e faz round-robin. Três containers RabbitMQ 4.1.4 formam o cluster; o teste inspeciona `members` e `online` da fila quorum. Não são três filas independentes. Testcontainers encaminha as portas do host para o proxy. O destino é um listener Kestrel local: zero acessos antes do cliente seguir Location e exatamente um depois.

`EndToEndTests.Creation_proxy_two_redirectors_and_three_node_quorum_preserve_contract_during_failures` cobre RF-19/20/21 e T09/T10/T13. A amostra de dez mensagens é coletada após confirmar recuperação do quorum e limpar os eventos de aquecimento. Cada tentativa de observação gera um novo GET/evento; nenhum evento incerto é republicado. O teste verifica o IP contra o valor observado pelo Caddy, além de rejeitar o IP falsificado.

Durante indisponibilidade dos três brokers desde a inicialização, as duas instâncias retornam 302 e readiness 200. Perda de um nó mantém maioria; perda de dois provoca resultados rejeitados/desconhecidos e preserva 302. Recuperação exige confirmações nas duas instâncias dentro de uma espera limitada. Há oito GETs concorrentes disponíveis e dezesseis leituras após o commit de desativação, todas 410. O primário recusa conexões de verdade, com sessões encerradas por uma conexão de manutenção; as respostas passam a 503 com Retry-After, e recuperam após restauração.

Diagnósticos `artifacts/redirection/t05-e2e-diagnostic*` registram correções do ambiente de teste: ordem de sondagem/cookie Erlang, espera pela recuperação Raft, portas dos clientes Kestrel, preparação do pool para concorrência e conexão de manutenção PostgreSQL. Não foram reaproveitados como provas de sucesso. A execução final acima é completa, com zero falhas/ignorados. `images.txt` registra IDs/digests reais; TRX separa tempos HTTP reais do orçamento determinístico de publicação testado com relógio controlado.
